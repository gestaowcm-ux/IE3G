# Project Guidelines: Nike Design System as Default

This project officially adopts the **Nike Design System** defined in [`DESIGN.md`](./DESIGN.md) as the default design standard for all UI, styling, layout, and component development.

All AI coding assistants and developers working on this project must strictly adhere to the guidelines, tokens, and rules documented in [`DESIGN.md`](./DESIGN.md).

## Quick Reference
- **Active Design System Spec**: [`DESIGN.md`](./DESIGN.md)
- **Primary Color**: `#111111` (Nike Black / Ink)
- **Background / Canvas**: `#ffffff`
- **Surface / Photo Stage**: `#f5f5f5` (Soft Cloud)
- **Buttons / CTAs**: Always pill geometry (`rounded: 9999px` / `rounded: 30px`), 48px height, `#111111` background with white text for primary. No sharp-cornered buttons.
- **Cards**: Flat, zero border radius (`0px`), zero box shadow.
- **Typography**: Heavy contrast between campaign display uppercase (Nike Futura ND / Bebas Neue / Anton at 96px, line-height 0.9) and clean Swiss sans UI text (Helvetica Now / Inter).
- **Red (`#d30005`)**: Reserved strictly for sale / markdown prices. Never used as background or decorative chrome.
